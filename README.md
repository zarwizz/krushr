# shrinkr

A lightweight, privacy-first desktop application designed for fast, high-quality image compression, batch format conversion, and smart resizing. Built with **Tauri v2**, a native **Rust** processing engine, and a sleek **TypeScript/Tailwind CSS** interface.

### Highlights
* **Local & Privacy-First:** All processing happens entirely on your machineno telemetry, no cloud uploads, and zero data collection.
* **Blazing Fast Engine:** Multithreaded native Rust backend engineered for quick batch execution.
* **Broad Format Support:** Convert and optimize between JPG, PNG, WebP, AVIF, HEIC, SVG, BMP, TIFF, GIF, and ICO.
* **Precision Controls:** Target specific file sizes, fine-tune compression ratios, and apply custom aspect-ratio-locked dimensions (Fit, Fill, Stretch) without upscaling artifacts.
* **Workflow Presets:** Built-in industry standard profiles alongside fully customizable, persistent user presets.
* **Modern Ergonomics:** Clean, dense, keyboard-friendly UI with dark mode and native bilingual support (English / French).
